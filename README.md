# ZEE-Entertainment-Enterprises-Limited
This project is an interactive Power BI Business Analytics Dashboard developed to analyze the financial performance, business growth, stock-market trends, and digital content performance of Zee Entertainment Enterprises Limited (ZEEL) and its streaming platform ZEE5.

The dashboard converts multiple datasets into meaningful business insights using data cleaning, data modeling, DAX calculations, interactive visualizations, and KPI analysis. The project is designed to demonstrate practical skills in Power BI, data analytics, data visualization, and business intelligence.

🎯 Project Objectives

The main objective of this project is to understand ZEEL's financial journey and evaluate the performance of ZEE5 from different business perspectives. The dashboard provides an interactive way to explore revenue, profitability, stock-price movements, content categories, languages, genres, ratings, views, and other important business metrics.

📌 Dashboard Pages
1. Financial Health Analysis
   
This page focuses on the financial performance of ZEEL. It provides insights into revenue, profit, share-price movements, and important financial KPIs. Interactive charts help identify performance trends and changes over time.

3. ZEE5 Content Analytics

This page analyzes the ZEE5 content library using multiple dimensions such as content type, language, genre, release year, ratings, titles, and views. KPI cards and visualizations make it easier to identify content trends and audience engagement patterns.

3. Downfall to Comeback Analysis
   
This page presents a business-performance analysis of ZEEL, highlighting important periods of decline and recovery. Stock-market and financial indicators are used to understand the company's performance journey.
